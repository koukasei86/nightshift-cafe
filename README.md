# Nightshift Café

ゾンビのシェフが働く、2Dカフェ経営ゲームです。横画面で店舗を見渡し、コンロ・来客・従業員をタップして営業します。

## v0.8.0 キャラクター・模様替え更新

- Seesaa攻略Wikiの一覧を「肉体労働者」まで参照し、22項目・33人（男女・無職5種を含む）を追加。旧セーブ用3人と初期シェフも保持しています。
- 来客 → **人物一覧 · 肉体労働者まで** で全員の人間/ゾンビ姿を確認できます。新しい人物は通常の来客としても出現し、感染後は同じ髪型・服装で働きます。
- 黄色い安全帽、ボブ・青髪・白髪・角刈り、四角い眼鏡、ベスト・スーツ・ドクロTシャツなどを共通のアニメーション対応描画へ組み込みました。
- 資料に画像がない人物は補完デザインです。画像が共通の職業は同じ外見です。原作の完全な複製ではなく、画像に基づいた描き直しです。能力値はゲームの既存バランスを維持しています。
- **模様替え**中は、家具を1回タップして選択、選択済み家具を再タップすると時計回りに90度回転。約0.45秒長押しするとつかめるので、そのままドラッグし、離して配置します。最後に**配置を確定**で保存します。

## Windowsで起動する

配布物の `Nightshift-Cafe.html` はエクスプローラーでダブルクリックすると開きます。以下はソースを編集する場合の手順です。

1. [Node.js公式サイト](https://nodejs.org/)から Node.js 24 LTS をインストールします。インストールすると `npm`（ゲームに必要なライブラリを入れる道具）も使えます。
2. このファイルと `package.json` があるフォルダで PowerShell を開き、次を実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

3. ブラウザで [http://127.0.0.1:5173](http://127.0.0.1:5173) を開きます。別のURLがPowerShellに出た場合は、そちらを開きます。終了はPowerShellで `Ctrl+C` です。

初回のライブラリ取得にはインターネット接続が必要です。起動後のゲームは外部APIやCDNに接続しません。進行は同じブラウザへ自動保存されます。非表示・終了中の経過は再開時に反映します。端末間同期やPWAのオフライン再起動は未実装です。

## 遊び方

1. 店内の**コンロをタップ**し、調理担当と料理を選びます。通常モードの「沼のポタージュ」は120秒です。右上の時間モードボタンで試遊モードにすると5秒になります。切り替えは次の調理から反映されます。
2. **完成したコンロをもう一度タップ**すると料理がカウンターに移ります。放置すると焦げます。従業員はカウンターから料理を取り、配膳して、会計後に皿を片付けます。
3. **お客様をタップ**すると雇用時の体力・移動速度・チップが分かります。毒素を使って感染させると、同じ人物が従業員になります。
4. **従業員をタップ**して体力を確認します。疲れていたら休憩を指示し、回復したら仕事に戻します。低体力で放置すると客を襲い、店の評価が下がることがあります。
5. **冷蔵庫をタップ**すると配膳台ごとの在庫を確認できます。コンロ・在庫の左側ボタンは撤去しました。ドラッグで視点を移動し、右上のボタンで拡縮・リセット・経路表示ができます。
6. **右斜め奥の青緑の扉をタップ**すると開閉できます。閉めると新しい客は引き返します。店内の客は食事・会計を続け、退店時だけ扉が一時的に開きます。

## ビルドとテスト

```powershell
npm.cmd test
npx.cmd playwright install chromium
npm.cmd run test:e2e
npm.cmd run build:standalone
npm.cmd run preview
```

単体テストは客やシェフのルールを調べます。画面テストはChromiumを自動操作します。`build` は配布用ファイルを `dist` に作ります。`preview` でその配布用ビルドをブラウザから確認できます。

## v0.5.0 の変更

- 配膳台A/Bごとに料理と予約数を管理。完成料理のメニューで移す台を選択できます。
- 客・従業員・料理を配膳タスクで結び、残り1食の二重予約を防止。途中取消では未受取分を解放し、運搬済みの料理は元の台に戻します。期限切れの料理は提供しません。
- カウンターメニューで先着順／距離優先を選択。経路表示ではタスクも確認できます。
- 通常／試遊モード、調理・掃除・休憩・暴走のポーズ、料理色を反映した運搬表示、途中の経路変更時の位置保持を追加。

通常モードの数値は調整中で、原作の全数値との一致を保証するものではありません。v0.5.0時点では家具編集・複数コンロ・襲撃・セーブ・PWAは未実装でした（追加コンロはv0.6.0で実装）。

## v0.6.0 家具ショップ（当時の仕様）

左側の「ショップ」から、コンロ100コイン、テーブル45コイン、椅子25コインで購入できます。営業の売上も購入に使えます。今回は固定の空きスペースへの自動設置で、追加コンロ1台・テーブルと椅子は各2個までです。椅子は追加テーブルを購入してから買えます。セットが揃うと接客席が4席から最大6席へ増えます。

追加コンロは直接タップ、またはコンロメニューの選択欄から使えます。注文はコンロごとに独立し、空いた従業員が担当します。従業員1人なら順番に調理し、複数人なら並行調理できます。

ショップ中は営業を一時停止します。通行予定の場所には設置できないので、その場合はショップを閉じて移動を待ちます。自由配置・移動・売却・カウンター購入は今回含みません。保存は未実装のため、再読み込みで購入状況も初期化されます。

## v0.7.0 作画・ゆっくり営業・保存・模様替え

- 4料理のイラストを具材、器、焼き目、陰影まで描き直し、レシピ帳・配膳台・運搬・食卓で共用。
- 歩行はv0.6の約半分。シェフ1.05、客は0.8075〜1.0925、雇用後は0.85〜1.3マス/秒。受取1.4秒、配膳1.8秒、食事16秒、来客間隔は約18.5〜22.55秒。
- 従業員の担当を「おまかせ／調理／配膳・片付け」から選択。「従業員」メニューで完成品の自動配膳台移動も設定できます。料理の繰り返し自動注文は未実装です。
- 「模様替え」で全家具を選び、長押しドラッグまたは詳細のマス選択で移動、90°ずつ回転。下書きを一括検証して確定します。入口封鎖・重なり・作業通路不足を拒否。椅子は隣のテーブルへ向けます。確定時は来客を退店扱いにし、未提供の予約・運搬料理を戻します。調理時間・在庫・所持金は保持します。
- 購入、配置、役割、体力、調理途中、料理在庫をlocalStorageへ保存。2秒ごとと操作・非表示時に保存します。保存不可は画面に表示。チェックサム・前回バックアップを用意しています。ブラウザのデータ削除・プライベートモードには注意してください。同一ブラウザ/同一URLの保存で、異なる端末への同期はしません。

### アプリを閉じている間

常駐処理ではなく、保存時刻と再開時刻の差を計算します。2分以内は通常のシミュレーションを進め、2分超は調理・休憩・在庫販売・疲労を集計します。長時間の移動・暴走・チップを画面内と完全一致させるものではありません。

営業中は待機疲労（毎分0.6）と実在庫・勤務可能な従業員に応じた売上が進みます。閉店中は新規販売と待機疲労を止めますが、開始済みの調理と休憩は続きます。休憩は毎秒0.25回復。調理完了から10分取り出さないと焦げ、配膳台の通常在庫は30分、試遊在庫は3分で期限切れになります。自動移動ONなら完成時に配膳台へ移ります。端末時計を使うローカルゲームです。
