# ゲーム仕様

## 横画面版の営業

| 項目 | 現在の設定 |
| --- | --- |
| 店舗 | 4席、コンロ1台、ゾンビシェフ1体、開店状態で開始 |
| 初期資源 | 120コイン、毒素3、評価3、従業員枠3 |
| 来客 | 1秒後に最初の客。その後は評価によって来店間隔が短くなる。最大9体 |
| レシピ | 序盤3種類とレベル2の1種類。材料費、時間、量、利益、体力消費が異なる |
| 調理 | 担当を指定できる。手が空いたときに調理を始め、完成後10分以内にコンロから取り出す |
| 在庫 | カウンターに移してから料理ごとの保持時間が進む。従業員が取りに行き、席へ配膳 |
| 会計 | 料理ごとの売価と、着席後55秒以内に配膳した場合の従業員別チップ。会計で経験値を得る |
| 評価 | 会計で上がり、待ち時間切れや従業員の暴走で下がる |
| 感染・休憩 | 来客を選んで毒素を使う。職種で体力・移動・チップ・費用が異なる。疲労で客を襲う前に休ませる |
| 片付け | 食後の皿が残る。皿を片付けてから次の客が座れる |
| 扉 | 右斜め奥の固定扉。直接タップ、または右上の営業表示で開閉。閉めると入店前の客が引き返す。通過済みの客は接客を続け、退店時には扉が一時的に開く |
| 歩行 | 客 0.855〜1.0925、シェフ1.05、雇用後0.85〜1.3マス/秒。v0.6の約半分 |

短いプレイで違いを試せるよう、時間・費用・体力の数値は今回の仮設定です。経験値24でレベルが上がり、毒素を1本得ます。

## 今後の機能

店舗拡張、従業員個別の育成・図鑑、他店舗への襲撃・戦闘、BGMと効果音、端末間のセーブ移行、PWA、Capacitor版。家具購入・配置・回転・ローカルセーブはv0.7までに実装。

詳細な現在の保存・不在進行・家具編集仕様はREADMEのv0.7.0節を参照。
