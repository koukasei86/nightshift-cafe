# NPC行動

## お客様

| 状態 | 開始条件 | 次の状態・割り込み |
| --- | --- | --- |
| approach | 営業中に出現し、右奥の扉の外側を目指す | 扉の外で席を確保し、開いていれば seating。閉店・満席・座席への経路なしなら leaving |
| seating | 到達可能な空席を確保 | 席に着くと waiting。扉を通る前に閉められた場合は leaving |
| waiting | 席に着いた | 配膳で eating。31秒経つと評価を下げ、席を解放し leaving |
| eating | 料理を受け取った | 3.4秒後に paying |
| paying | 食事を終えた | 0.8秒後に売上・経験値を加算。席を解放して leaving。皿がテーブルに残る |
| leaving | 会計完了、満席、閉店または待ち時間切れ | 歩道の出口で削除。出口への経路が見つからない場合はその時点で削除 |

来客の感染時は従業員に移行します。低体力の従業員が暴走した場合、会計中以外の周囲の客が退店し、店の評価が下がります。

## 従業員

| 状態 | 開始条件 | 次の状態・割り込み |
| --- | --- | --- |
| idle | 新規開始時、または仕事完了 | 調理注文、配膳、片付け。体力が限界なら暴走または休憩 |
| toStove | コンロへの経路確保 | 作業タイルで cooking。作業タイルに到達できない注文には材料費を返す |
| cooking | コンロに到着 | 時間経過で完成。プレイヤーが取り出した時点で在庫を追加。従業員は idle、休憩を予約していれば resting |
| toCounter | 待っている客を担当 | カウンターに在庫があり客が待機中なら1食取り出して toTable |
| toTable | 料理を取り出した | 配膳地点で serving |
| serving | 配膳地点に到着 | 0.6秒後、客が待機中なら配膳し体力を消費。取り消し時に期限内の料理を返却 |
| toClean / cleaning | 汚れた席を担当 | 皿を片付けて体力を消費。座席が再利用可能になる |
| resting | 操作による休憩または疲労で自動休憩 | 体力が回復。仕事に戻す操作で idle |
| outburst | 体力が限界で店内に食事中・料理待ちの客がいる | 客が逃げて評価が下がる。短時間後に resting |

A*は家具や入口以外の境界タイルを避けます。探索するマス数はグリッドの面積で上限を設けます。到達できない座席・配膳先は候補から外します。座席・配膳対象・片付け対象は同時に1人が確保します。通路ではNPC同士が同じタイルを通れます。NPCの衝突回避と家具移動後の経路更新は次段階の検証対象です。
