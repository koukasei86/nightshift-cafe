## 動作

Web Audioをユーザー操作後に開始。初期音量45%、消音と音量はゲームセーブとは別キーで端末・ブラウザごとに保存。最大6音、同じ音の短時間連打抑制、ピーク制限とコンプレッサーを設定。音の作成や再生が使えない場合もゲームを起動可能。

実際の営業状態の変化を固定更新ごとに観測するため、料理完成・自動配膳台移動・会計の音は各タイミングで1回。購入音はショップで即時。ページ非表示で再生を停止し、復帰時は音の観測基準をリセット。不在時間分の会計音・完成音を連続再生しません。

## 検証

型検査、単体51件、関連画面5シナリオ成功。14音を22.05/44.1/48kHzで生成し非無音・有限値・最大振幅・両端のゼロを検査。実際のAudioContextの開始、14音の再生開始、消音/音量保存、バックグラウンド停止と再開、調理→配膳→会計での再生開始を確認。

OfflineAudioContextでゲームと同じ音量・コンプレッサーを通し、13.5秒の試聴WAVを作成。最大振幅0.329。これは信号と再生開始の確認であり、原作との聴感比較やiPhone実機確認ではありません。
