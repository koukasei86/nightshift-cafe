# Midnight Reserve — v0.10

依頼: おしゃれなバーや海外の上品なレストランに合う、ダンディーなジャズ。

オリジナル作曲・合成音源。Ebを中心に、maj9・m9・13thとマイナーii–Vを含む32小節AABA、76 BPM、約101.053秒。控えめな旋律、余白のあるピアノのコード、ウォーキングベース、ブラシ/ライド。ピアノの倍音ごとの減衰とわずかな弦のずれ、低音の胴鳴り、短いステレオ残響を合成しています。既存曲や録音サンプルは使用していません。生演奏の録音ではありません。

再生成: scripts/build-jazz.py（numpy、lameencが必要）。ゲーム内MP3には周回端の余韻を付け、デコード後に32小節ぶんを切り出します。末尾8msの微小な圧縮境界差を補正し、無音を挟まずループ。初回の音出し操作後に読み込み、音量28%から開始。BGM用ゲインは効果音ゲインと分離。ページ非表示時には停止し再生位置を保存、表示復帰時には続きからフェードインします。

PCMマスター: 44.1kHz stereo、peak 0.76、RMS 0.1355。ゲーム同梱は160kbps MP3、約2MB。配布HTMLにも埋め込み、外部配信・音楽アカウントは不要。

検証: 型検査・単体51件成功。BGM独立音量/消音、設定復元、旧消音設定の移行、1本のみの再生、隠した時間の停止と続きからの復帰、101.053秒のステレオループと境界サンプル差をブラウザで検証。効果音の従来の2シナリオも再実行。iPhone実機・スピーカーでの聴感調整は未実施。
