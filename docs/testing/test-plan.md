# テスト計画

## 初回Web版

| コマンド | 確認内容 |
| --- | --- |
| `npm.cmd test` | 営業一巡、右奥の入口経由、閉店時に入店前の客が引き返すこと、閉店後の退店、歩行速度、20分相当の座席重複・退店監視、入口とコンロの封鎖、料理の差、休憩と暴走、同時配膳 |
| `npm.cmd run test:e2e` | Chromiumでの調理・取り出し・会計・閉店。844×390の横画面で右奥の扉を直接開閉、シェフとコンロを順に直接タップ、客のタップ・雇用・休憩・復帰 |
| `npm.cmd run build` | TypeScriptの型検査と配布用ビルド |

## 機能追加時

- NPCを増やし、同時作業、作業中の指示変更、家具連続移動、封鎖からの回復を検証する。
- 保存後に再起動して状態を比較する。調理途中の終了、破損検出、旧形式の移行、バックアップ復元、保存中断、連続復帰を検証する。
- PWAを実機のホーム画面に追加して初回起動する。キャッシュ完了を確認して完全終了し、機内モードで再起動する。調理・接客・襲撃後に保存、完全終了、再起動し、保存状態と照合する。
- iPhone 14 Plusと対象iPadでそれぞれ、デバイス、OS、プレイ時間、fps、フレーム時間、メモリ、音声割り込みを記録する。
